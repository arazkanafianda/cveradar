
# CVERadar

**A Lightweight CVE Monitoring and Retrieval Tool**

CVERadar is a Python-based cybersecurity tool designed to retrieve and monitor recently published Common Vulnerabilities and Exposures (CVE) records.

Built with Google Colab, CVERadar provides a simple way to retrieve recent vulnerability information within a user-defined timeframe and result limit.

The project aims to make vulnerability monitoring more accessible, efficient, and convenient for cybersecurity enthusiasts and security researchers.

## Features

- **Recent CVE Retrieval** – Retrieve recently published CVE records.
- **Customizable Timeframe** – Specify how far back to search for vulnerabilities.
- **Adjustable Result Limit** – Choose how many CVE records to retrieve.
- **Google Colab Integration** – Run directly in Google Colab without local installation.
- **Lightweight & Simple** – Designed for quick vulnerability information retrieval.

## Getting Started

### Run with Google Colab

No local installation is required.

1. Open the notebook using the link below.
2. Connect to a Google Colab runtime.
3. Execute the notebook cells.
4. Configure the desired CVE retrieval limit.
5. Run the script to retrieve recent CVE records.

**[Open CVERadar in Google Colab](https://colab.research.google.com/github/arazkanafianda/cveradar/blob/main/CVERadar.ipynb)**

### Run Locally

Clone the repository:

```bash
git clone https://github.com/arazkanafianda/cveradar.git
```

Navigate to the project directory:

```bash
cd cveradar
```

Open `CVERadar.ipynb` using Jupyter Notebook or JupyterLab.
